# wifi-bridge

[![CI](https://github.com/jagajaga/wifi-bridge/actions/workflows/ci.yml/badge.svg)](https://github.com/jagajaga/wifi-bridge/actions/workflows/ci.yml)

Share Wi-Fi passwords from an Android phone to a Mac that is **not yet on any
network** — the way an iPhone offers "Share Password" to a nearby MacBook.

The transport is Bluetooth Low Energy, so it works with no Wi-Fi and no internet.

## Pieces

| Folder     | What                                                                 |
|------------|----------------------------------------------------------------------|
| `android/` | Kotlin app: encrypted network vault, import via share menu, BLE responder |
| `macos/`   | Swift menu-bar app: asks nearby phone for a password, joins via CoreWLAN |
| `docs/`    | Design notes — start with [docs/design.md](docs/design.md)           |

## How it is meant to feel

1. Once: pair the Mac and the phone (scan a QR code shown by the Mac).
2. Once per network: on the phone, open Wi-Fi → network → **Share**, and share
   the QR image (or paste the password) into wifi-bridge.
3. Later, on the Mac: pick the network in the wifi-bridge menu (or let it notice
   you are offline). The phone shows "Share password for *X* with MacBook?" —
   tap **Share**, and the Mac joins.

## Install

Download both apps from the [latest release](https://github.com/jagajaga/wifi-bridge/releases/latest):

- **Android 10+:** `wifi-bridge-<version>.apk`
- **macOS 14+:** `WiFiBridge-<version>-macos.zip` — ad-hoc signed, not notarized;
  on first launch right-click → Open, or run
  `xattr -dr com.apple.quarantine /Applications/WiFiBridge.app`.

Build from source: [android/README.md](android/README.md),
[macos/README.md](macos/README.md).

## Development

- Protocol: [docs/protocol.md](docs/protocol.md). Both apps test against
  `docs/test-vectors.json`, generated by an independent Python implementation:
  `pip install cryptography && python scripts/gen_test_vectors.py`.
- CI (`.github/workflows/ci.yml`) checks the vectors are reproducible, runs the
  Android unit tests + lint + build, the Swift core tests on Linux and macOS, and
  builds the universal macOS app.
- Releases: push a `v*` tag; `.github/workflows/release.yml` builds the signed APK
  and the macOS zip and publishes a GitHub release.
